# 阅读 — Flutter 首版设计

## 授权与取舍

用户要求使用 Flutter，参考 Legado 的机制，做微信读书式阅读应用，并明确授权自主决策、不询问常规问题。本设计据此直接选择实现方案，不等待交互批准。Flutter SDK 必须安装在 `D:\ProgramFiles\flutter`。不自动提交或推送应用变更。

三种可行路线：完整移植 Legado（复杂且涉及 GPL 代码移植）、仅做静态 UI（不可用）、独立实现离线阅读与声明式书源子集（选定）。首版优先完整的读书闭环，不虚构社交关系、付费商城或云同步。

## 产品

- 名称：阅读。中文界面，自己的标识与书封，不复制微信读书商标或素材。
- 四个主入口：书架、发现、书源、我的。窄屏底部导航，宽屏左侧导航与约束内容宽度。
- 首次运行即可打开公版节选。示例明确标记为节选，不冒充全本或在线内容。
- 书架：真实搜索、分类筛选、最近阅读排序、网格/列表切换、继续阅读、移除确认、TXT 导入。
- 发现：本地公版书目与已启用远程书源搜索。远程搜索必须由用户提交；不同书源的失败独立显示，不影响离线书籍。
- 书源：导入 JSON 对象/数组（支持粘贴或文件），启停、删除、查看规则。导入时报告不支持的规则，不静默丢弃行为。
- 我的：全局阅读偏好、书签笔记入口、隐私说明与关于；仅展示真实本地数据，不伪造阅读时长、点赞或好友动态。

## 阅读器

采用稳定的章节纵向阅读，暂不实现仿真翻页。保留目录、上一章/下一章、书签、笔记与设置。字体大小、行距、纸张/白色/夜间主题即时应用并持久化。窄屏与桌面均限制行长，正文支持文本选择。

进度以章节和段落锚点保存，不保存屏幕页码。滚动产生的高频状态留在阅读组件，存储防抖；切章、离开与生命周期暂停时刷新。重开、调整字体与改变视口后恢复到同一段落附近。书签记录章节、段落与摘录；可填写笔记并跳转回来。正文缓存成功后可离线重开。

## 架构

Flutter Material 3 + 自定义主题；使用 Flutter 自带 ChangeNotifier 管理低频应用状态，不引入不必要的状态框架。

- `lib/domain/`：不可变 Book、Chapter、ReadingPosition、Bookmark、ReaderSettings、BookSource。
- `lib/data/`：Sembast 持久层；原生端应用数据目录，Web 端 IndexedDB；内存数据库用于测试。首启种子事务化且有版本标记，删除书架后不重新灌入。
- `lib/services/`：TXT 解码/分章、声明式书源校验与 CSS 解析、受限 HTTP 抓取。
- `lib/application/`：书架/书源/设置/内容缓存协调。存储成功后才通知 UI，失败有可读提示。
- `lib/ui/`：导航、书架、发现、书源、个人页、阅读器与公用书封。
- `assets/`：公版节选、原创建图形与可再分发字体；资源不依赖在线 CDN。

网络、解析、存储和组件分开；测试可以替换 HTTP 客户端和数据库。用户导入的书籍和书源仅留在本机。没有账号系统、遥测或自建云端。

## Legado 声明式子集 v1

参考上游 `bba5c64df32bcc9d23ac2b3f2f717b00b0ea01b9` 的数据格式，独立编写 Dart 实现。上游 GPL-3.0；不复制 Kotlin 实现或上游资源。参考路径见 `docs/BOOK_SOURCES.md`。

支持文本书源 `bookSourceType: 0`，以 `bookSourceUrl` 为身份；`ruleSearch`、`ruleBookInfo`、`ruleToc`、`ruleContent` 可以是对象或编码为字符串的 JSON。支持 `@CSS:` / `@css:` 选择器与 `@text`、`@ownText`、`@textNodes`、`@html`、常见属性提取，支持相对 URL 与精确的 `{{key}}`、`{{page}}`、`{{baseUrl}}` URL 占位符。初版只提供 HTTP(S) GET 和 UTF-8 HTML，单页目录/单页正文。

不支持 JavaScript、WebView、XPath、JSONPath、旧版链式与索引扩展、规则组合、正则后处理、动态登录、收费解锁、目录/正文自动翻页。发现实际依赖这些行为的字段时拒绝该来源并展示具体字段原因。普通描述性未知元数据保留，不解释为脚本。

请求设超时、响应大小与重定向上限，只允许 HTTP(S)，不执行远程代码。浏览器遵守 CORS，绝不通过关闭浏览器安全机制或公共代理绕过。Android 远程联网需要运行时可达来源；默认没有擅自加入的第三方盗版来源。

## TXT 与离线边界

支持 UTF-8、UTF-8 BOM、UTF-16 BOM；错误编码明确提示转换为 UTF-8。限制文件 2 MiB，识别常见中文章节标题，没有标题时按段落分段。导入和删除需要保存成功才更新列表，不静默丢数据。

## 视觉方向

清晰、安静、有书卷感。浅暖灰背景、白色内容区、深墨文字、克制的蓝色强调。书封以大字排版与简单几何构成，每本不同而整体一致；不用随机图、装饰性仪表盘或虚假的营销数据。阅读页优先留白与长文舒适度。按钮有可辨识的触控区域、键盘焦点与语义标签。

## 验收

1. Flutter 分析无错误，所有自动化测试通过，Web release 构建成功。
2. 浏览器实测窄屏与宽屏：打开书、切章、目录跳转、修改设置、创建与删除书签笔记、刷新恢复。
3. TXT 导入测试覆盖正常章节、无章节、BOM、错误编码、空白与超限。
4. 书源测试通过受控 HTTP fixture 验证搜索→详情→目录→正文→离线缓存，覆盖脚本拒绝、相对 URL、超时/HTTP 错误。
5. 存储测试验证首启幂等、删除不复活、进度/设置/笔记往返与内容缓存。
6. 尝试原生 Android 构建；如果缺少 Android SDK 或网络阻断，准确记录未验证项，不宣称 APK 已完成。
7. README 给出运行命令、SDK 路径、支持范围、隐私说明与验证记录。完成后将任务状态设为 completed，并停用恢复任务。
