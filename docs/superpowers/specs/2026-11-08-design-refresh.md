# 「阅读」按完整设计稿重构说明

## 决策

本轮以 `docs/阅读助手_完整设计稿.html`（下称“设计稿”）为唯一视觉与信息架构基准，重做 Flutter 端的入口层与界面层，不重写已有的导入、书源、搜索、缓存、阅读分页等业务逻辑。设计稿的 27 个页面与状态（`screens` 注册表）逐个对应到现有能力：能落地的按稿重排，暂不具备底层能力的（听书语音引擎、WebDAV 网络同步、模型问答）以“明确标注的本地实现”落地，不伪造效果。

以下取舍是本轮的核心决定。

### 一、信息架构：底部三项

设计稿固定底部「书架 / 发现 / 我的」。现状是四项，多一个「书源」。本轮把书源移进「我的 → 书源管理」，作为可压栈的独立页面打开，`AppShell` 只保留三个 tab。理由：设计稿的功能取舍表把“书源维护”列为“收起”，日常入口不应为维护型功能保留一个常驻位。

宽屏侧栏保留，但同步改成三项 + 「书源管理」页内入口；侧栏不再重复渲染四屏 `IndexedStack`。

### 二、设计 token 对齐

`lib/ui/theme.dart` 的 `AppColors` 改为设计稿色板，并保留既有语义命名，避免大面积重命名：

- `ink` `#252932` → `#23262C`
- `muted` `#626976` → `#858B96`
- `blue` `#2468DE` → `#2878F0`
- `background` `#F7F8FA` → `#F3F4F6`
- `line` `#E7E9EE` → `#EDF0F3`
- `softBlue` `#EDF3FF` → `#EDF4FF`
- 新增 `paper` `#F6F3EC`（阅读米色）、`night` `#202225`（阅读夜间）、`green` `#4A8B74`（护眼）

字号与圆角按稿：页标题 28 / 分区标题 18 / 正文 16（界面）/ 19（阅读正文）；按钮圆角 10、轻卡片 12、底部面板 22。

### 三、壳层与状态栏

设计稿的 `.statusbar`（9:41 + 信号电池）与 `.homebar`（Home 指示条）是原型外壳，**不进入应用**——真机由系统绘制。实现只取壳内内容：`.app-main`（圆角内容区）、`.tabbar`（三项，选中蓝字 + 图标下小圆点）、`.app-topbar`（返回 + 标题 + 右侧操作）。

### 四、书架：沿用已交付的分组卡片，补齐设计稿细节

书架的分组卡片（2×2 拼贴、`在读 N`、组内层）已在 `61f291a` 交付，与设计稿一致，保留。本轮补齐：

1. 标题行改为大标题「书架」28px + 两个圆形图标按钮（搜索、添加），移除现有「调参」按钮的可见文案。
2. 标题下方新增筛选行：`全部状态 ∨` + `N 本书` + `选择`。
3. 网格末尾新增「添加书籍 / 导入 · 搜索」虚线卡。
4. 组内层补齐 `添加书籍 / 从书架选择` 卡与页脚 `N 本书 · 组名`。
5. 页脚说明改为「长按书籍或分组，即可整理书架」。

### 五、发现：保留书源浏览能力，按稿重排

设计稿发现页 = 大标题 + 搜索框（右侧蓝色「搜索」）+ 提示 + 最近搜索 + 浏览书源 + 添加书源 + 说明。现有 `discover_screen.dart` 已实现浏览/内容两模式并接 Legado 的 `exploreUrl` 分类，能力更强，本轮只重排外观与入口：

- 顶部大标题「发现」+ 右侧「管理发现来源」图标（跳书源管理）。
- 搜索框提交后进入搜索页（不再内联出结果）。
- 最近搜索 chips 复用现有搜索历史存储；没有历史时不渲染该块。
- 「浏览书源」按设计稿列出行项：图标、名称、`分类` 或 `仅搜索` 能力标签、描述；点击有分类的书源进分类页，仅搜索的书源进限定来源搜索。
- 无书源时显示 `暂无书源` 空状态（设计稿 `noSources`）。

### 六、阅读页：设计稿的沉浸式排版

阅读页按稿重做视觉层，保留现有分页/恢复/缓存/朗读实现：

- `reader-head`：书名 + `· 章节名`，右侧 `N / M`。
- `reader-paper`：章节标题 + 正文；首段首行不缩进（稿中 `.first-paragraph`），段间距按行距设置。
- `reader-footer`：左侧章节名，右侧 `进度% · 页/总页`。
- 点击中央唤出工具；左右各 1/6 宽度为翻页热区。
- 工具顶栏：返回、书签、更多；工具底栏：进度条 + 上一章/下一章 + 四项（目录、换源、笔记、设置）。
- 夜间模式按稿：背景 `#202225`、正文 `#C3C0B8`。

### 七、阅读助手：本地实现，明确标注

设计稿把阅读助手列为“新增轻量辅助”，并要求“答案显示章节引用”“本设计稿为预设示例回答，不连接模型”。本轮不接入模型，落地为**本地回顾**：

- 入口：详情页 `读之前，先认识这本书`、阅读页划线的「解释」、读完页的「和助手聊聊这本书」。
- 内容由本机数据推导：当前章节名、已读章节、本书笔记条目、选中段落原文；不生成虚构事实。
- 面板底部固定注明「本地回顾 · 不连接模型」。
- 这样既满足设计稿的信息结构，也不伪造 AI 能力。

### 八、暂不落地项

设计稿中的以下页面没有对应底层能力，本轮不做假实现，只在需要的位置给出可理解的提示：

- 听书（`audio`）：现有 `read_aloud` 使用系统 TTS，播放器页按稿做基础版（播放/暂停、进度、上一章/下一章、语速、目录），睡眠定时与 15 秒快进在系统 TTS 下不可靠，暂不提供。
- WebDAV 同步（`backup` 的同步块）：只保留现有本机备份，WebDAV 行标注“本版本未接入”。
- 阅读统计（`stats`）：现有 `readingActivities` 可推导“本周时长/阅读书籍/笔记数”，按稿实现；不引入打卡、排名。

### 九、测试策略

重构不得降低既有覆盖率与行为。原则：

- 触达的每个页面保留现有测试断言，改写因文案/结构变化的断言（如 `阅读` 标题、`我的书架` 文案、四 tab → 三 tab）。
- 新增按稿验收的 widget 测试：三 tab 导航、书架大标题与添加卡、发现页三段结构、我的页统计卡与列表行、详情页底部双按钮、阅读页工具底栏四项、阅读助手的本地回顾与声明文案。
- P006 门禁：`dart format --output=none --set-exit-if-changed lib test`、`flutter analyze --no-pub`、`flutter test --no-pub`。

## 验收

1. 底部导航为「书架 / 发现 / 我的」三项；书源管理从「我的 → 书源管理」进入并可返回。
2. `AppColors` 与设计稿色板一致；全应用无残留旧色值（`#2468DE`、`#F7F8FA`、`#E7E9EE`、`#252932`、`#626976`）。
3. 书架：大标题 + 搜索/添加按钮 + 筛选行 + 分组卡 + 单书卡 + 添加卡 + 页脚提示；组内层有添加书籍卡与页脚；无分组时退回平铺网格。
4. 发现：大标题 + 搜索框 + 最近搜索 + 浏览书源列表（能力标签）+ 添加书源；无书源时为空状态。
5. 我的：头像/昵称/签名/齿轮 + 统计卡（累计阅读、读完的书、读书笔记）+ 列表行（读书笔记、阅读记录、导入书籍、书源管理、备份与同步、通用设置）+ 引言。
6. 详情：封面/书名/作者/类型 + 标签 + 三项指标 + 助手入口 + 简介 + 目录行 + 笔记行 + 底部「已在书架 / 继续阅读」。
7. 阅读页：书名与章节头、正文、页脚进度、中央唤出与左右热区、四项工具底栏；夜间为 `#202225` / `#C3C0B8`。
8. 目录：简介块 + 章节搜索 + 目录/书签切换 + 序号章节行 + 当前章高亮。
9. 阅读设置：亮度/字号/字体/行距/背景/翻页六行；换源面板按稿分段。
10. 阅读助手面板显示真实章节引用与笔记，并固定标注「本地回顾 · 不连接模型」。
11. 所有页面在 390×844 与 ≥1000 宽屏下不横向溢出。
12. P006 三项门禁通过，测试数与改动前持平或增加；`flutter build apk --release` 成功并在 MuMu 模拟器逐屏走查。
