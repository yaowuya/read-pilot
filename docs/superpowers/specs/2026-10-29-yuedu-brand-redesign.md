# 「阅读」品牌重设计说明

## 决策

产品正式名称为 **阅读**。名称只使用中文，不再显示旧品牌名或新的英文品牌名。仓库名、Dart 包名、Bundle ID、数据库文件名和 IndexedDB 名继续保留 `read-pilot` / `read_pilot`，这些是内部技术标识，改动会引入包迁移和用户数据丢失风险。

备选方向曾包括“卷舒”（展卷从容）、“兰台”（古代藏书机构）和“墨栖”（诗意书房）；用户明确选择“阅读”，因此不再延伸命名。

## 图标概念

主题为 **月下展卷，一方朱印**。图标不写汉字，避免小尺寸笔画糊成一团：

- 宣纸底：`#F2E8D5`，传达书页和温润质感。
- 墨色：`#28302C`，绘制展开书卷；两页顶部形成远山般的起伏，中缝是书脊。
- 朱砂：`#A54636`，作为月轮和闲章边框，是唯一品牌强调色。
- 辅助灰绿：`#6F7B70`，只用于纸纹或大尺寸细节，不进入小图标主体。

图标使用平面色块和清晰负形，不使用渐变、书法字体、照片或复杂纹样。安全区至少占画布边长的 12%；在 16、20、29、32、48、192、512、1024 px 检查清晰度。Android 自适应图标前景保留足够裁切区；iOS、Web、Windows 使用同一母版。

## 应用内品牌

`BrandMark` 与启动图标使用相同的书卷、月轮、朱印构图。根据用户补充约束，主界面的科技蓝、冷灰背景、导航选中态、按钮和正文颜色全部保持原样；宣纸、墨色与朱砂只用于品牌图标本身，不改变已有界面配色、信息架构和交互。

侧栏文案：

- 产品名：阅读
- 标语：让阅读，自由发生
- 保留“在书页之间，遇见自己。”作为页尾句。

用户可见的应用标题、关于页、内置公版书源、样例正文署名、Web manifest、Android label、iOS display name、Windows 产品信息、README 与设计文档统一改名。测试同步断言新名称，并增加旧名称残留扫描。

## 生成与维护

新增 `tool/generate_brand_assets.py`，用 Pillow 从同一几何母版生成：

- `assets/branding/icon-master.png`
- Web favicon、普通和 maskable 图标
- Android 各 density launcher PNG 和 v26 自适应图标资源
- iOS AppIcon 全尺寸
- Windows ICO

脚本只负责图形资产，不修改代码或品牌文案；生成后会检查每个目标的尺寸、透明度和文件可读性。启动页不再显示旧品牌。

## 验收

1. 全仓用户可见内容统一为“阅读”；内部 `read_pilot` / `read-pilot` 允许保留并在 README 说明。
2. Flutter 分析无错误，全部自动化测试通过，Web release 构建成功。
3. 图标脚本可重复执行；所有平台目标尺寸正确，ICO 含多尺寸。
4. 在 512 px 和 32 px 查看母版；真实浏览器检查桌面和手机书架，标志不模糊、不溢出，图标内朱砂色可辨，同时应用背景和蓝色操作色与改名前一致。
5. 不提交、不推送；更新部署包和 SHA-256，停用恢复检查。
