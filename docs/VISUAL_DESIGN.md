# 阅读视觉说明

## 数据与工作

- 对象是书籍、章节、段落、阅读位置、书签和个人书源，不是营销统计。
- 初次书架三本，发现页六本，全部为有明确来源的公版节选。
- 默认没有已读时长、好友数据、评分或阅读进度；用户操作之后才产生记录。
- 常用动作是继续阅读，一次点击即可进入最近书籍。
- 导入 TXT 和管理书源是次级动作，不与正文争夺注意力。
- 书籍封面是稳定的原创排版，不使用随机占位图。
- 主体受众是中文长文阅读者，手机为主，宽屏为辅。
- 读书进度使用章节与段落锚点，与字体和窗口大小解耦。
- 导航必须清晰命名阅读产品以及书架/发现/书源/我的范围。
- 非联网场景依旧能读、记、调整字号；网络失败留在受影响来源内。

## 方向

使用 tasteskill 的 `editorial-greeting`（seed `1077129984`），因为它适合个人长期使用的轻界面，而非金融仪表盘。保留既有 Noto Sans SC、科技蓝操作色和冷灰背景；古风宣纸、墨色与朱砂仅用于新品牌图标，不扩散到应用界面。

首屏问题：现在读哪一本？最大内容是正在读的书及真实的书架，而不是大数字。品牌形状采用朱砂闲章、墨色展卷与一轮月；书封大字、书脊以及分节线条提供“属于阅读”的视觉材料。

- 书架：继续哪本书？近期阅读在上，书封与搜索/筛选在下。
- 发现：下一本读什么？公版书籍简介与分类，也可搜索已启用书源。
- 书源：我的书从哪里来？能力范围、启用状态与明确的导入入口。
- 我的：如何让阅读更舒适？可操作偏好与真实书签笔记入口。
- 阅读器：专心读这一段。正文占主体，操作收敛在顶/底栏。

## 视觉约束

应用主色保持 `#2468DE`，墨色 `#252932`，次级文字 `#626976`，背景 `#F7F8FA`，白色面板；品牌图标独立使用宣纸 `#F2E8D5`、图标墨色 `#28302C` 与朱砂 `#A54636`。夜间正文使用中性近黑而非蓝黑。界面色彩主要用于一个主要操作，不使用渐变、玻璃、伪造数据、彩色图标方块或花哨入场动画。所有图标按钮有语义标签。

手机左右边距 20，宽屏内容限制 1100；宽屏侧栏 224。正文最大宽度 720，手机正文边距 24。标题不超 32，常规正文 14–16，阅读正文 18–32 可调。书封同一比例，布局等间距；书名在小屏保留两行。

Flutter 使用 CanvasKit，DOM/CSS 检查器不能代表实际绘制样式。验证以 Flutter 组件测试、真实浏览器截图、语义树、无溢出与交互测试为准；不把 CSS 检查器不适用伪称为通过。
